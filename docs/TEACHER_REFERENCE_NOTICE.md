# Teacher Reference Separation

`OneDrive_1_2026-7-25.zip` is the teacher's official reference package and must
be retained unchanged.

The delivery archive contains:

- `teacher_reference/`: byte-for-byte extracted reference files; and
- `working_program/`: the application controller plus clearly documented
  minimal corrections required to compile and match the hardware I/F PDF.

The reference corrections are listed individually in `BUG_REPORT.md`. They
must not be described as changes to the hardware design.
